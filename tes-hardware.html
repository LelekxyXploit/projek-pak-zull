Project Overview

Tentang Website

Tujuan Pembelajaran

Website ini dibuat sebagai media pengenalan perangkat keras komputer dengan tampilan interaktif. Pengunjung dapat mengetahui bentuk perangkat, nama, fungsi, kegunaan dan hubungan perangkat tersebut dengan sistem komputer.

  • Mengenali perangkat keras komputer.
  • Memahami fungsi setiap perangkat.
  • Mengetahui contoh penggunaan perangkat.
  • Melihat model perangkat dalam bentuk 3D.
  • Memahami komponen komputer secara dasar.

Cara Menggunakan

Gunakan pencarian untuk menemukan perangkat. Gunakan filter kategori untuk mempersempit daftar. Klik salah satu perangkat untuk membuka halaman detail.

Pada halaman detail terdapat model 3D. Model dapat diputar menggunakan mouse atau touchpad, diperbesar dengan scroll, dan dikembalikan ke posisi awal dengan double-click.
